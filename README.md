# Consultoría Backend: E-commerce de Proximidad

Este repositorio contiene la **Actividad 1.2: Elige tu Stack**, donde actuamos como consultores tecnológicos para una startup local. El objetivo es orientar a su equipo directivo no técnico sobre arquitectura web (conceptos cliente/servidor, frameworks, infraestructura) y realizar una Prueba de Concepto (PoC) básica en el servidor.

## Contenido del Repositorio

*   **[`Informe_Consultoria.md`](./Informe_Consultoria.md)**: Informe técnico y arquitectónico breve que justifica las decisiones tecnológicas propuestas (como el uso de PHP y Laravel).
*   **[`fichero_demostracion.php`](./fichero_demostracion.php)**: Script básico en PHP que actúa como demostración práctica (PoC) para comprobar que el entorno local funciona correctamente.

## Cómo probarlo en local (XAMPP)

1.  Asegúrate de copiar esta carpeta del proyecto dentro del directorio público de tu servidor local (por defecto, `C:\xampp\htdocs\`).
2.  Abre el panel de control de XAMPP y verifica que el servicio de **Apache** esté iniciado.
3.  Abre tu navegador web y accede a través de `localhost` utilizando rutas relativas. Por ejemplo: 
    `http://localhost/Act_servidor/Act_1.2_Elige_tu_Stack/fichero_demostracion.php`
    *(Ajusta la ruta según cómo hayas nombrado las carpetas intermedias en tu equipo).*
